# Support

Agent Signaler is an early project maintained without a service-level agreement.

Before requesting help:

1. Read the [README](README.md) and [user guide](docs/user-guide.md).
2. Check [known acceptance gaps](docs/ACCEPTANCE.md).
3. Reproduce with the latest `main` build using synthetic or disposable fixtures.
4. Remove credentials, account identifiers, connection URIs, private URLs,
   machine names, logs containing environment data, and unrelated source code.

Use a GitHub issue for reproducible non-security defects and feature requests.
Use [private vulnerability reporting](SECURITY.md) for security concerns.

Questions involving production Azure resources, enterprise policy, network
exposure, software licensing, or deployment approval require the relevant
administrator or legal/security owner; this project cannot authorize those uses.
