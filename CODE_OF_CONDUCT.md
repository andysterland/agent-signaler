# Code of Conduct

Agent Signaler contributors must communicate professionally and make the project
welcoming to people with different backgrounds and levels of experience.

Expected behavior includes:

- discussing ideas and defects respectfully;
- giving actionable technical feedback rather than personal criticism;
- respecting privacy, security reports, and disclosure boundaries;
- accepting maintainer decisions about project scope and safety;
- correcting mistakes without harassment or retaliation.

Harassment, threats, discrimination, sexualized conduct, deliberate disclosure of
private information, and sustained disruptive behavior are not acceptable.

Report conduct concerns privately through the repository owner's GitHub profile.
Do not include sensitive personal information. Maintainers may edit or remove
content, close participation channels, or restrict contributors when needed to
protect the community and project.
